# sonic-sample

**预制 .swsonic 包集合 —— 直观展示 [Sonic](https://github.com/lambdaS-zh/sonic) 离线回放能力的示例仓库。**

本仓库通过 GitHub Releases 发布预先录制的 `.swsonic` 包，每个包均来自真实在线网站的录制或本地网站的录制。你可以下载任意包，使用 **Sonic Player** 在完全离线的环境下体验原页面的网络交互效果。

---

## 快速开始

1. 前往 [Releases](https://github.com/lambdaS-zh/sonic-sample/releases) 下载所需的 `.swsonic` 文件。
2. 安装 [Sonic Player](https://github.com/lambdaS-zh/sonic/releases)。
3. 双击 `.swsonic` 文件或用 Player 打开它，即刻进入离线浏览模式。

> 无需联网，无需额外配置。

## 关于 Sonic

Sonic 是一款网页请求录制与离线回放桌面工具，由 [Creator] 录制、[Player] 回放。本项目仅提供示例包，不涉及 Sonic 源码或实现细节。如需了解 Sonic 本身的功能与用法，请移步主仓库：

👉 [lambdaS-zh/sonic](https://github.com/lambdaS-zh/sonic)
